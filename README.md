# Event Management System

A simple React web app built using Redux Toolkit and the Ticketmaster Discovery API.

## Features
- User registration, login, and logout with local storage persistence.
- Browse and search live events via Ticketmaster Discovery API.
- Filter events by classification and city.
- View event details and register/cancel bookings.

## Tech Stack
- React.js
- Redux Toolkit & React-Redux
- React Router DOM
- Ticketmaster Discovery API v2

## Setup & Run
1. Clone the repo and install dependencies:
   ```bash
   git clone [https://github.com/soaer01/event-management-system.git](https://github.com/soaer01/event-management-system.git)
   cd event-management-system
   npm install
   ```
